# إعداد جزيرة Saeed داخل UEFN

هذه الخطوات هي مسار الإعداد العملي. الملفات الموجودة في GitHub وحدها لا تنشئ مشروع UEFN كاملاً؛ يجب إنشاء المشروع وحفظه أول مرة من UEFN على Windows.

## 1. جلب أصل الشخصية والتحقق منه

من جذر نسخة هذا المستودع على Windows:

1. افتح PowerShell في مجلد المستودع.
2. شغّل:
   `powershell -ExecutionPolicy Bypass -File Tools/Download-SaeedAsset.ps1`
3. إذا كان مستودع المصدر خاصاً، وفّر متغير البيئة `GH_TOKEN` بصلاحية قراءة المستودع. لا تضع الرمز داخل ملف أو ترفعه إلى GitHub.
4. افحص الملف:
   `python Tools/validate_glb.py assets/Saeed_AI-3D.glb --json`

التحقق البنيوي لا يثبت أن كل الميزات مدعومة في UEFN. احتفظ ببصمة SHA-256 في تقرير الاستيراد.

## 2. إنشاء مشروع UEFN حقيقي

1. ثبّت وافتح Unreal Editor for Fortnite (UEFN) من Epic Games Launcher.
2. أنشئ مشروع جزيرة جديداً باستخدام قالب بسيط، واحفظه باسم `SaeedFortnite`.
3. لا تنقل ملفات المشروع إلى مسارات عشوائية؛ اترك UEFN يدير ملف المشروع ومجلدات المحتوى وملفات Verse.
4. من Content Browser، أنشئ مجلد أصول باسم `Saeed` داخل مجلد المشروع.

## 3. استيراد GLB

1. جرّب استيراد `assets/Saeed_AI-3D.glb` عبر مسار استيراد الأصول الذي تدعمه نسخة UEFN المثبتة.
2. سجّل كل الخيارات والتحذيرات التي يعرضها المستورد.
3. افحص اتجاه النموذج وقياسه ونقطة الارتكاز وملامسة الأرض.
4. افتح النموذج وافحص المواد، والعيون والأسنان واللسان، والهيكل العظمي، والحركات، وMorph Targets.
5. لا تفترض أن استيراد GLB يعني الاحتفاظ بكل الحركات أو تعابير الوجه. إن فقد المستورد ميزة، سجّلها قبل تعديل الأصل.

## 4. إعداد NPC تجريبي

1. أنشئ NPC Character Definition من Content Browser.
2. اختر نوع NPC الذي تسمح به نسخة UEFN للأصل المستورد. راجع قيود Character Cosmetic Retargeting؛ لا تفترض أن أي GLB يمكن تعيينه مباشرةً دون إعادة استهداف أو هيكل متوافق.
3. عيّن اسم العرض `Saeed`، واختر Verse Behavior واربط `saeed_npc_behavior` بعد أن يترجم الملف بنجاح.
4. اسحب تعريف الشخصية إلى مستوى اختبار بسيط لإنشاء/إعداد NPC Spawner.
5. تأكد من وجود أرضية قابلة للملاحة (navigation mesh) حول نقطة الظهور؛ سلوك التجوال لن يعمل إذا كانت الوجهة غير قابلة للوصول.

## 5. ترجمة واختبار

1. أنشئ ملف Verse من Verse Explorer أو انقل الكود إلى مسار Verse الذي يديره UEFN. ملف Verse في جذر GitHub ليس بديلاً عن ملف مضاف إلى مشروع UEFN.
2. شغّل Verse > Build Verse Code، ثم عالج أخطاء المترجم قبل متابعة الاختبار.
3. اضغط Launch Session.
4. تحقّق من أن سعيد يظهر مرة واحدة، ويقف على الأرض، ويتحرك داخل النطاق، ولا يخرج من منطقة الاختبار.
5. اختبر كل حركة مستوردة منفردة بعد التأكد من أنها موجودة فعلاً في Content Browser.
6. أعد تشغيل الجلسة وتأكد من ثبات النتيجة.

## 6. سجل الأدلة

لكل محاولة، احتفظ بـ:
- إصدار UEFN وتاريخ الاختبار.
- اسم الأصل المستورد وحجمه وSHA-256.
- رسائل الاستيراد والتحذيرات.
- أخطاء ترجمة Verse إن وجدت.
- صور من Content Browser ومن جلسة اللعب.
- نتيجة كل اختبار: Pass / Fail / Not tested.

لا تُعلّم أي اختبار بأنه ناجح لمجرد نجاح GitHub Actions. GitHub Actions هنا يفحص أدوات Python فقط ولا يستطيع تشغيل UEFN أو Fortnite.

# Island base and asset policy

- **Base island:** create a new Blank island from the installed UEFN Project Browser. This avoids importing an unrelated creator's map or binary assets.
- **Epic content:** use only assets and templates permitted by the applicable Epic/UEFN terms. “Free to use” does not mean public domain or unrestricted outside Fortnite.
- **Saeed model:** assets/saeed.glb is the source asset tracked in this repository. Preserve its source file; work on converted copies.
- **Third-party maps:** do not copy a published island's .umap, .uasset, textures, meshes, or Verse code unless its license explicitly grants the required rights. A public GitHub repository alone is not a license.
- **Verification:** record the license URL and allowed uses for every external asset before including it in a distributable project.

The repository can prepare source files, scripts, and documentation. Only UEFN can create/save its native map and project metadata and confirm the resulting island in-editor.

# Saeed Fortnite

مشروع مستقل لتجهيز شخصية **Saeed** كـ NPC داخل جزيرة Fortnite باستخدام Unreal Editor for Fortnite (UEFN).

## الهدف

- استيراد نموذج Saeed من ملف GLB الأصلي بعد التحقق من توافقه.
- إعداد NPC مخصص داخل جزيرة UEFN، وليس Fortnite Battle Royale skin.
- ربط الشخصية بالحركات المناسبة واختبار الخامات والهيكل العظمي.
- إضافة سلوك NPC عبر Verse عند الحاجة، مع إبقاء الإعدادات الخاصة بـ UEFN موثقة.

## مصدر الشخصية

المصدر الأولي للنموذج:
`Saeed-V2.0/assets/Saeed_AI-3D.glb`

لا يُنسخ النموذج إلى هذا المستودع تلقائياً؛ يُتحقق من النسخة والمقاس والترخيص قبل إضافته أو تحويله.

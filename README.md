# Saeed Fortnite

مشروع مستقل لتجهيز شخصية **Saeed** كـ NPC داخل جزيرة Fortnite باستخدام Unreal Editor for Fortnite (UEFN).

## الهدف

- استيراد نموذج Saeed من ملف GLB الأصلي بعد التحقق من توافقه.
- إعداد NPC مخصص داخل جزيرة UEFN، وليس Fortnite Battle Royale skin.
- ربط الشخصية بالحركات المناسبة واختبار الخامات والهيكل العظمي.
- إضافة سلوك NPC عبر Verse عند الحاجة، بعد التحقق من دعم واجهات UEFN المستخدمة.

## مصدر الشخصية

المصدر الأولي للنموذج: `Saeed-V2.0/assets/Saeed_AI-3D.glb`.

ملف GLB غير موجود حالياً في هذا المستودع. لا تُعتبر معلومات النموذج أو نتائج فحصه السابق بديلاً عن فحص النسخة الفعلية التي ستُستورد.

## أدوات المطور

- `Tools/validate_glb.py`: فحص بنيوي لملفات GLB دون مكتبات خارجية.
- `Tests/test_validate_glb.py`: اختبارات آلية للحالات الصحيحة والتالفة.
- `.github/workflows/asset-tooling.yml`: يشغّل الاختبارات وفحص صياغة الأداة. إذا لم يكن ملف GLB موجوداً، يوضح السجل ذلك صراحةً ولا يدّعي نجاح فحص الأصل.

تشغيل الفحص محلياً يتطلب Python للمطور فقط؛ لا توجد متطلبات Python للمستخدم النهائي أو للاعب.

## حدود مهمة

فحص بنية GLB لا يثبت أن UEFN يدعم كل الحركات أو الخامات أو Morph Targets. GitHub Actions لا ينشئ جزيرة UEFN ولا يختبرها داخل Fortnite. يلزم الاستيراد الفعلي في UEFN على Windows قبل إعلان توافق الأصل أو نجاح الـ NPC.

راجع `Docs/IMPORT-CHECKLIST.md` لتسجيل نتيجة الاستيراد والاختبارات الفعلية.

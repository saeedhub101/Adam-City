# Palestine data

The automated free source currently uses the Geofabrik Israel and Palestine OSM extract; this is not a Palestine-only extract. It is explicitly named and documented to avoid misrepresenting coverage.

Regions: Jerusalem, Ramallah/Al-Bireh, Nablus, Jenin, Tulkarm, Qalqilya, Salfit, Jericho, Bethlehem, Hebron, Gaza Strip subregions, and Tiberias/Eilat boundary context.

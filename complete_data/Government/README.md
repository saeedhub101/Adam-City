# Government datasets — Adam City

This folder contains copies of government-sourced datasets that are already present in the repository. Existing source files were left unchanged.

## Imported government agency

### DPWH — Department of Public Works and Highways
Location: `DPWH/`

Copied datasets:
- National road network — 286 features in the saved import report.
- Road surface type — 990 features.
- Number of lanes — 939 features.
- Bridge inventory — 61 features.

These counts are feature counts from the existing report, not guaranteed counts of unique physical roads or bridges. The files are clipped to the project's Ermita/Rizal Park area of interest, which is a rectangular project window rather than an official administrative boundary.

## Sources identified for future investigation, not yet imported here

# NAMRIA-related datasets — Ermita

This folder contains copies of three existing project datasets requested for organization under `complete_data/Government/NAMRIA/data/`.

## Files copied

- `ermita-copernicus-dem-cropped.tif` — copied from `ermita/3d/terrain/ermita-copernicus-dem-cropped.tif`.
- `esa-worldcover-2021-10m-ermita.tif` — copied from `ermita/maps/sources/landcover/esa-worldcover-2021-10m-ermita.tif`.
- `vegetation-grass-classes-ermita.geojson` — copied from `ermita/maps/sources/landcover/vegetation-grass-classes-ermita.geojson`.

The copies reuse the original Git blobs, preserving their contents exactly. The original files remain in place.

## Source attribution note

These files were grouped here at the user's request. Their filenames indicate Copernicus DEM and ESA WorldCover for the first two datasets; this folder placement alone does not establish that NAMRIA created or distributed them. Confirm the original source and license metadata before attributing them to NAMRIA.

# DPWH — Department of Public Works and Highways

Copies of the government-derived DPWH datasets already stored in the Adam-City repository.

## Contents
- `data/`: four clipped GeoJSON layers.
- `metadata/`: the original import report with source endpoints, dates/vintages, counts and limitations.
- `scripts/`: the script used to retrieve and clip the DPWH layers.

The source files under `ermita/maps/external/` remain unchanged. Feature counts and source vintages are documented in the metadata report. The project clipping rectangle is not an official Ermita boundary.

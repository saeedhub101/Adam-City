# Named building image sources — review register

This register contains specifically identified reference photos discovered during visual research. A source is considered identity-supported when the Wikimedia file page names the building and/or its structured data identifies the depicted building. This does **not** mean the photo has already been projected onto a model or that camera angle/coverage has been validated for texturing.

## 1. Luneta Theater

- Building identity: Luneta Theater, Kalaw Avenue corner L. Guerrero Street, Ermita, Manila.
- OpenStreetMap reference on Commons category page: way/90311602.
- Photo: [Top façade of Luneta Theater in Ermita, Manila - 1.jpg](https://commons.wikimedia.org/wiki/File:Top_fa%C3%A7ade_of_Luneta_Theater_in_Ermita,_Manila_-_1.jpg)
- Evidence: file page places the photo in the Luneta Theater category and structured data identifies Luneta Theater as depicted.
- Photographer: Judgefloro.
- License stated on file page: public domain, released by the copyright holder.
- Date: 27 July 2016.
- Intended use: visual reference for facade form, color, roofline, and surrounding context. The file description is a broad scene description, so inspect the actual image and crop before using it as a facade texture.
- Additional references: [Luneta Theater category](https://commons.wikimedia.org/wiki/Category:Luneta_Theater), containing seven image files.

- Photographer: Judgefloro.
- License stated on file page: public domain, released by the copyright holder.
- Date: 27 July 2016; description says the church was under restoration at the time.
- Intended use: facade/architectural reference only. Account for restoration-era scaffolding/conditions if present; do not assume it depicts the current state.
- Additional references: [Main facade of Malate Church category](https://commons.wikimedia.org/wiki/Category:Main_facade_of_the_Malate_Church), containing 117 files.

## Required checks before applying any image

1. Open the source image itself at high resolution and inspect framing, visible facade, occlusions, lighting, and current-vs-historical differences.
2. Match the depicted building to the target building footprint and camera-facing side.
3. Use only a correctly aligned crop/decal or material workflow; do not move or replace the OpenFreeMap building geometry.
4. Preserve source page, photographer, license, and review decision alongside any derived texture.
5. Do not treat nearby geotagged images as identity proof. Do not apply these photos to any GLB automatically.

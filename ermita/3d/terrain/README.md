# Ermita terrain data

This folder contains a cropped Copernicus elevation surface and a simple terrain mesh for visualization. It is a regional-resolution DSM, not a survey-grade bare-earth terrain model.

- [3D terrain surface](ermita-terrain-surface.glb)
- [Cropped GeoTIFF](ermita-copernicus-dem-cropped.tif)
- [Import report and source attribution](terrain-import-report.json)

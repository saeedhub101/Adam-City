# Terrain and elevation

Store only DEM/DTM/DSM and terrain files that are available for the project area and may legally be redistributed in this public repository.

For every raster, document:
- provider and product name
- coverage and acquisition date
- pixel size / resolution and vertical datum
- coordinate reference system
- DEM, DTM or DSM type
- licence and written permission if applicable
- processing steps and checksums

A 3D basemap viewer may display elevation or imagery without providing a downloadable source file. Do not scrape map tiles or assume imagery is reusable. NAMRIA/Geoportal products require product-specific checks. No terrain raster has been imported yet.

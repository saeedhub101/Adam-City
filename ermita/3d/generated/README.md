# Generated Ermita 3D building model

ermita-buildings-extruded.glb is generated from OpenStreetMap building polygons. It contains simple extruded volumes, not textured or photorealistic buildings. Heights use OSM tags where available and documented estimates otherwise. See building-height-methods.csv and the map import report. Source: OpenStreetMap contributors, ODbL 1.0; attribution and share-alike obligations apply.
